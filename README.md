# SVM Kernels: Understanding the Impact of Different Kernels on Classification Performance

## Overview
This repository contains a tutorial showing how different SVM kernels affect classification performance on synthetic and real datasets. The tutorial includes code, figures, and a PDF write-up.

## How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Open `svm_kernel_tutorial.ipynb` in VS Code or Jupyter
3. Run all cells to reproduce figures and results

## Outputs
The notebook saves figures such as:

- svm_kernels_comparison.png
- svm_scaled_comparison.png
- breast_cancer_confusion_matrix.png
- rbf_hyperparameter_tuning.png
